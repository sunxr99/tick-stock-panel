# Sector Strength / Relative Strength 描述正确性验证

## 范围与口径

- 这是**状态描述**验证，不是未来收益预测、选股回测或买卖信号评估。
- 使用 2024 年跨季度固定十个完整交易日：`01-31`、`02-28`、`03-29`、`04-30`、`05-31`、`06-28`、`07-31`、`08-30`、`09-30`、`11-29`。
- 每个日期均对当日完整一级行业和完整有效股票横截面计算冻结后的结果；每条记录只使用该日及之前的 enriched 前复权 `close` 派生的 `change_pct`。
- Sector 按最终 `SectorStrengthResult.percentile` 分层；RS 按同日最终 `rs_score` 的降序横截面 percentile 分层。RS 仅使用唯一的一级行业 context，因此没有概念多归属的重复计数。
- 本报告没有计算 T+N、MAE、MFE、Profit Factor 或任何未来标签，也没有修改公式、权重、阈值或字段。

## 结论

1. **Sector Strength 能正确描述当前板块强弱。** 四个相对收益窗口、两个 Breadth 原始字段和 persistence 均呈预期的总体单调性。
2. **Relative Strength 能正确描述当前个股相对强弱。** 过去收益、相对市场、相对行业，以及两个 RS 子 percentile 都从 Top 至 Bottom 单调下降。
3. **未发现代码或排名方向问题。** 使用的是降序 rank；数值越高，percentile 越高。最终 RS 分层也基于最终 `rs_score`，没有二次反转。
4. **更像短期过热而不是稳定强势的读法应保留。** RS Top 10% 的 P90 分别为：3 日收益 29.41%、5 日 36.65%、10 日 42.17%、60 日 60.34%；Sector Top 10% 的 strong_stock_ratio P90 为 91.00%。这些是“当下很强/可能已延展”的描述证据，不能单独推导为可持续性或买入结论。

该验证只证明当前定义的**描述正确性**；它不对未来收益、交易时点或候选池阈值作任何判断。
