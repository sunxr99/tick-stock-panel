# 数据边界与金融口径

## 数据边界

Provider 负责供应商字段、单位、日期和代码格式到内部标准数据集的转换；通用功能通过能力声明和 Provider 访问。TickFlow 专属代码必须被隔离，不能使未启用的 Provider 主流程失效。

数据写入后需按任务检查：持久化 Parquet、仓库/内存缓存、generation 或版本、SSE 通知、前端 Query 失效。不能以“文件已写入”替代一致性验证。

## 不可混用口径

- 自定义实时入口的 `change_pct` 与 `turnover_rate` 为小数制（`0.0366` = `3.66%`；`0.05` = `5%`）。enriched 的 `turnover_rate` 为百分数值（`5` = `5%`）。指数展示缓存可能使用百分数口径；跨边界必须显式转换并测试。
- enriched 的 `open/high/low/close` 为前复权价格；`raw_close/raw_high/raw_low` 为原始价格。涨跌停、一字板、炸板与价格限制依赖原始价及交易日规则。
- A 股时段按北京时间。分钟 K 的 `datetime` 为北京时间墙钟（naive）；日线、分钟线和实时快照必须明确交易日归属。
- 历史换手率优先采用公告日不晚于目标交易日的历史股本；无数据才降级到最新维表，不能按报表期提前泄露。

这些规则是稳定约束，不替代任务中的实际字段追踪：先以 Serena 定位 Provider、normalizer、仓库与测试，再读最小实现范围。
