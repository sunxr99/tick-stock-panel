# 大盘风险 V1

## 目标与边界

大盘风险 V1 是日终市场状态快照，不是交易信号，也不输出未经验证的加权风险分。它保留原始指标、分子分母、覆盖率和解释性风险线索；数据缺失只能显示为 `partial` / `insufficient_data`，不能解释为低风险。

### 风险提示等级

`risk_level` 是便于看板阅读的规则化提示，不是经收益回测校准过的预测概率，也不替代每条风险原因。

| 等级 | 条件 |
| --- | --- |
| `unavailable`（数据不足） | 任一必需指标缺少数据。不会降级为低风险。 |
| `low`（低） | 没有触发风险维度，且两指数并非同时处于 MA60 下方。表示“暂未发现”，不表示未来低波动或可买入。 |
| `watch`（中） | 触发 1 个独立风险维度，或两指数虽在 MA60 下方但市场强度仍不低于 50 分且无额外内部恶化。 |
| `elevated`（偏高） | 触发 2 个独立风险维度，或两指数同时处于 MA60 下方且市场强度低于 50 分。 |
| `high`（高） | 短期趋势同步破位（两指数在 MA20 下且 MA20 下行）、市场强度低于 35 分、并伴随卖压或新低扩散；或至少 3 个风险维度同时触发且强度低于 45 分。 |

独立维度为“指数趋势、市场广度、卖压、新低扩散”。同一维度内的多条事实只算一次，避免例如“下跌家数占优”和“下跌成交额占优”被重复放大。每条快照同时保存 `risk_signal_categories` 与 `risk_signal_category_count`。

### 阶段、顶部预警与修复候选

这三项是研究性状态标签，不是“预测某天见顶”或“确认可以抄底”的承诺：

| 字段 | 含义与规则 |
| --- | --- |
| `market_phase` | `uptrend_healthy`：两指数都在 MA60 上且无顶部预警；`top_warning`：中证全指仍在 MA60 上，但出现内部背离；`weakening_confirmed`：两指数同时跌破 MA60，或两者均处于 MA20 下且 MA20 下行；其余为 `mixed`。 |
| `top_warning_level` | 只在中证全指仍在 MA60 上计算。独立线索是 MA50 广度连续三日下降、250 日新低多于新高、最近三日中至少两日的下跌家数与下跌成交额同时占优。1/2/3 项分别为关注/偏高/高。 |
| `recovery_candidate` | 仅在两指数并非都在 MA60 上时观察。MA50 广度连续三日改善、买盘重新占优、中证全指位于 MA20 上且 MA20 上行，至少同时出现两项才标记为 `candidate`。它是修复候选，不能替代趋势反转确认。 |

各字段同时保存对应的 `*_categories`，因此看板显示的不只是结论，也会列出触发它的事实。

### 低位震荡识别

`low_level_consolidation` 用来区分“指数破位后的继续下跌”与“低位止跌后的震荡修复”，不等同于趋势反转。只有两指数仍在 MA60 下方、同时处在各自近 60 日价格区间下部（中证全指不高于 35%、沪深300不高于 45%），并且至少出现三项改善，才进入此状态：指数短期止跌、市场强度较 5 个交易日前回升至少 5 分、新低家数回落、ATR14/收盘价收敛、MA50 广度连续三日修复、卖压缓解。

进入该状态后，原本因两指数同时跌破 MA60 产生的“高”风险会降为“偏高”，但只有重新收复 MA60 且内部指标同步改善，才可称为中期趋势修复。看板会显示每项已满足的止跌依据与两指数的 60 日区间位置。

### 市场强度分与历史折线

`market_strength_score` 是 0–100 的连续研究指标，用于观察市场内部动能的变化，而非预测收益率或替代风险等级。它要求五类数据全部可用；任一类不可用时为 `null`，看板明确显示数据不足。

| 组成 | 权重 | 连续口径 |
| --- | ---: | --- |
| 指数趋势 | 30% | 中证全指、沪深300分别按 MA60 关系 50 分、MA20 关系 25 分、MA20 方向上行/走平/下行 25/12.5/0 分，再取均值。 |
| 市场广度 | 25% | `((站上 MA20 比例 + 站上 MA50 比例) / 2) × 100`。 |
| 市场参与度 | 20% | 涨跌家数平衡分与 `100 × (1 - 下跌成交额占比)` 的均值。 |
| 新高新低 | 15% | `100 × 新高家数 / (新高家数 + 新低家数)`；若两者均为零，视为中性 50 分。 |
| 量能健康度 | 10% | 当日有效股票总成交额/MA20 与 MA5/MA20 分别线性映射后取均值；0.70/1.30 是当日相对 MA20 的低/高参考，0.85/1.15 是 MA5 相对 MA20 的低/高参考。成交额偏向上涨或下跌仍只在“市场参与度”计入，避免重复计分。 |

看板展示最近 60 个已计算交易日的折线及 30/45/55/70 参考线。70 以上为强、55–70 偏强、45–55 均衡、30–45 偏弱、30 以下为弱；这些区间是阅读刻度，尚未经过收益回测校准。

## 数据与口径

| 项目 | 口径 |
| --- | --- |
| 股票范围 | `kline_daily` 中当日 `volume > 0`、`amount > 0`、`close > 0` 的股票。停牌、当日无成交和无效收盘价不进分母。 |
| 股票均线 | 原始日线收盘价的 MA20 / MA50。分母还要求该股票有完整的对应交易日窗口；上市不足窗口的新股不计入。 |
| 涨跌家数 | 有效股票相对该股票前一条已落盘日线收盘价的涨跌。没有前收的股票不计入涨、跌、平及成交结构。 |
| 成交结构 | `down_amount / (up_amount + down_amount)`；平盘股成交额不进入这个比率。 |
| 量能窗口 | 有效股票当日成交额之和为全市场成交额，MA5 / MA20 均按实际已有交易日滚动计算；窗口不足时量能健康度不可用，不以低量能代替。 |
| 新高/新低 | 有效股票当日最高价达到近 250 条日线最高值、或最低价达到近 250 条日线最低值。窗口不足 250 条时不可用。 |
| 指数趋势 | 中证全指 `000985.SH`、沪深300 `000300.SH` 的收盘与 MA20 / MA60 关系；MA20 方向为相对前一交易日 MA20 的上行、下行或走平。 |
| 波动率 | 两个指数的 ATR14 / 当日收盘价；ATR 使用标准 True Range。 |
| 交易日 | 从 `kline_daily/date=...` 分区解析实际已有交易日，不按自然日补齐。 |

当前本地全市场复权因子只覆盖少量个股、每只最多 18 个交易日，不能作为全市场历史前复权口径。因此 V1 显式保存 `price_basis=raw_unadjusted`，并在看板提示这一限制。后续补齐全市场逐日复权因子后，可新增独立版本而不混用历史结果。

## 持久化与触发

- 结果路径：`data/market_risk_history/part.parquet`
- 唯一键：`date`；同一交易日重算会覆盖旧行，不重复追加。
- 日终管道在原始股票与指数日线已完成后执行：首次仅回填最近 60 个交易日用于趋势展示；后续每次重算最新交易日。
- 历史回填必须显式调用 `POST /api/market-risk/recompute?start=YYYY-MM-DD&end=YYYY-MM-DD`，避免日终任务误做全历史扫描。

## API

- `GET /api/market-risk/latest`：最近快照。
- `GET /api/market-risk/date/{YYYY-MM-DD}`：指定已计算交易日，不会在读取时触发计算。
- `GET /api/market-risk/history?limit=20`：近期趋势；也支持 `start`、`end`。
- `GET /api/market-risk/coverage`：快照覆盖范围与方法版本。
- `POST /api/market-risk/recompute?start=...&end=...`：显式历史覆盖计算。

## 风险线索

V1 仅给出可直接追溯的线索，例如指数低于 MA20/MA60、MA20 下行、下跌家数占优、下跌成交额占优、250日新低多于新高，或“中证全指仍在 MA60 上方但 MA50 广度连续三日下降”。这些线索不会合成为分数，也不作为买卖规则。
